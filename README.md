# mini-rag

## About

This repository contains my study notes and implementation based on @bakrianoo's [mini-rag tutorial](https://github.com/bakrianoo/mini-rag).

## Main Technologies

- Python programming
- FastAPI (web framework)
- Retrieval-Augmented Generation (RAG) concepts
- RESTful API development
- Uvicorn (ASGI server)
- Dependency management with pip

## Features

- Minimal Retrieval-Augmented Generation (RAG) example
- Simple and easy to understand codebase
- Based on FastAPI and Python

## Prerequisites

- Python 3.8+
- [pip](https://pip.pypa.io/en/stable/)

## Installation

Clone this repository and install the dependencies as described in the original [mini-rag repository](https://github.com/bakrianoo/mini-rag):

```bash
git clone https://github.com/bakrianoo/mini-rag.git
cd mini-rag
pip install -r requirements.txt
```

## Running the App

Start the FastAPI server with:

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 5000
```

Then open your browser and navigate to `http://localhost:5000` or use the interactive docs at `http://localhost:5000/docs`.
